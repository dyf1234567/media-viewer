# 图片查看器功能清单

> 双击图片进入;播放列表 = 当前的筛选/搜索结果;右侧详情面板同屏联动(翻图自动跟随)。
> 更新日期:2026-10-02(对应 v1.3.2)

## 浏览

| 功能 | 操作 |
| --- | --- |
| 上一张 / 下一张 | `←` `→` 方向键,或工具栏右端 ‹ › 按钮 |
| 退出查看 | `Esc` 或「返回」按钮(淡出动画) |
| 页码指示 | 顶部「3 / 17」 |
| 全屏 | `F` 或全屏按钮(再按退出) |
| 幻灯片轮播 | 轮播按钮,每 3 秒自动下一张;再点停止 |
| 视频播放 | 视频文件进入自带播放器(进度条/音量/循环) |

## 缩放与平移

| 功能 | 操作 |
| --- | --- |
| 缩放 | 滚轮(以光标为锚点,幅度随滚动量线性变化,0.1x–10x) |
| 步进缩放 | `+` `-`(或 `=` `_`) |
| 适应窗口 | `0` 或双击图片,或「适应窗口」按钮 |
| 缩放滑杆 | 顶部滑杆拖动,百分比实时显示 |
| 平移 | 左键拖动,松手带轻惯性滑行;期间不触发界面重渲染 |
| 自动适配 | 打开/切换图片时自动适配窗口(小图也放大铺满) |

## 图片编辑(写盘,图库记录同步更新)

| 功能 | 操作 | 说明 |
| --- | --- | --- |
| 旋转 90° | `R` 或旋转按钮 | 暂存,不弹保存动画 |
| 水平翻转 | 翻转按钮 | 同上 |
| 暂存写盘时机 | — | 切换图片 / 退出查看 / 进入裁切 / 打开编辑器时自动统一保存 |
| 未保存提醒 | — | 有暂存变换时工具栏出现「未保存」角标 |
| 裁切 | 裁切按钮 | 默认全选整图;四角 + 四边 8 个把手往里收;实时像素尺寸;`Esc` 取消 |
| 编辑器 | 编辑按钮 | 亮度/对比度/饱和度、旋转、裁剪、另存为 PNG/JPG/WEBP/BMP |

## 右侧详情面板(同屏联动)

- 大图预览(24vh 固定高度,等比完整显示)、格式徽章
- 主题色药丸行(点击复制色值)
- 文件名(双击重命名)、评分、收藏、删除
- 注释输入框
- 标签(添加/移除)、文件夹(归类)
- 直方图(颜色/R/G/B/亮度 + 统计值,可折叠)
- AI 生成参数:正向/负向提示词、**多候选提示词切换**(复用工作流串图时对照画面选择)、模型、采样参数、原始 workflow,可折叠
- 摄影参数(EXIF)、视频信息,可折叠
- 缺失文件「重新定位」

## 放大镜(计划)

鼠标悬停在图片上时,光标位置出现圆形局部放大镜(2x/4x 可切),显示该区域的放大画面;移动鼠标即可隔镜检查全图细节(手指、五官等),无需整图放大再拖回。滚轮可在悬停时临时调整放大倍率。

## EXIF 浮层(计划)

按 `I` 键(或悬停角标)在图片上方浮出半透明信息卡,集中显示当前图的技术参数:

- 通用:分辨率、文件大小、格式、修改时间
- 实拍图:相机/镜头/光圈/快门/ISO/焦距
- AI 图:模型、采样器、步数、CFG、种子

无操作数秒后自动淡出,或再按 `I` 关闭;不遮挡常驻界面。

## 删除/收藏快捷键(计划)

看图时全程键盘操作,批量筛选效率核心:

| 键 | 行为 |
| --- | --- |
| `Del` | 删除当前图(弹确认;确认后自动跳到下一张继续看) |
| `L` | 收藏/取消收藏当前图(心形即时反馈,面板同步) |

## 对比前后图(计划)

与播放列表中的相邻图快速对比,两种模式:

- **并排模式**:当前图与上一张(或下一张)左右并排,同步缩放平移
- **滑动分割**:两图重叠,拖动中间分割线左右擦除,逐像素对比

用途:同一提示词批量出图的横向择优、修图前后对比。入口:`C` 键或工具栏对比按钮,`Esc` 退出。
