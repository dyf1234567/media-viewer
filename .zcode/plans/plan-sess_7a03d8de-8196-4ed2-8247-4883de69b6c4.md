# Media Viewer 核心闭环实施计划(第一阶段)

技术栈:**Electron + electron-vite + TypeScript + Vue 3 + Pinia**;原生依赖 sharp(缩略图/图像处理)、better-sqlite3(图库数据库)、chokidar(文件监听)、exifr(EXIF)、ffmpeg-static/ffprobe-static(视频信息/缩略图/转封装)。界面语言:中文。

项目建在当前目录(`D:\Program Files (x86)\Media viewer`),与规格文档并列;若 node_modules 写入遇到权限问题,再和你商量挪目录。默认图库位置 `%USERPROFILE%\Pictures\MediaViewerLibrary`(设置中可迁移)。

## 明确 deferred(第二阶段)
第 9 章「对比工作台」全部内容(双图四模式/多宫格/双视频盲测与 PSNR-SSIM 曲线)。本阶段先交付对比托盘的攒料与校验逻辑,工作台入口置灰并提示「下一阶段提供」。除此之外规格其余章节全部在本阶段落地。

## M1 脚手架 + 窗口框架 + 数据层
- electron-vite 项目初始化(main/preload/renderer 三段结构)、ESLint 可选不做
- 无边框窗口:自定义标题栏(拖拽区、置顶、最小化、最大化/还原、关闭)
- 三栏布局(侧栏/素材区/详情面板)按钮折叠;宽度不足自动紧凑模式;窗口尺寸位置、各折叠态、视图状态持久化
- 全局错误提示条(4s 自动消失);renderer 崩溃兜底页(重载/关闭/查看错误详情)
- SQLite 库表:`assets`(content_hash 唯一去重、路径、尺寸、评分、收藏、缺失态、回收站时间戳、colors/exif/ai_meta/video_info JSON 缓存)、`tags`、`asset_tags`、`albums`、`album_assets`、`settings`(kv)、盲测战绩表(本期建表备用)
- 图库目录结构:`media/ thumbs/ video-cache/ trash/ library.db`
- 注册 `mv://` 自定义协议直读本地文件(支持 Range,视频流式播放不整段进内存)
- 原子写工具(临时文件 + rename),SQLite 开 WAL

## M2 导入 + 缩略图 + 图库浏览
- 导入管线:stat → 流式 sha256 → 内容去重复用 → 引用/复制入库 → 排队生成缩略图;进度 n/total 可取消;结束报告(入库/复用/跳过/失败及每项原因,可展开)
- 三个入口:工具栏按钮(可选导入方式)、拖拽(全屏遮罩确认,默认引用)、「添加目录」(递归扫描、同名相册按路径去重、支持多选目录)
- 缩略图:sharp 生成 800px WebP,并发队列;视频取第 1 秒帧(时长不足取首帧);缺失分批重建
- 瀑布流(默认):按原始宽高比分列、长图不裁切、卡片文件名+尺寸;列表视图:表头列齐全;两种视图虚拟滚动(高度由数据库尺寸预计算,滚动条稳定)、占位骨架、接近加载
- 缩略图 100–400px 连续可调;6 种排序;文件名模糊搜索(回收站同样可用)
- 12 维筛选全部实现(格式/形状/标签/相册/颜色系/评分/两日期/注释/尺寸/大小),已启用条件以标签展示、点 × 移除
- 侧栏:固定入口(全部/收藏/未分类/未标签/回收站,实时角标)、相册列表(首图封面+成员数)、底部外观与设置入口
- 状态栏:当前范围素材数与总大小
- 随机浏览(打乱取前 50);标签总览页(搜索/新建/重名校验/100 字符上限/点击跳转过滤)

## M3 选择批量 + 详情面板
- 完整选择模型:单击/Ctrl/Shift/拖框(Ctrl 追加)/Ctrl+A/Esc;方向键与 J/K 导航(瀑布流按列)、Shift 扩展、自动滚入视野;空格开预览

- 批量操作条:存进库(引用转复制)、收藏切换、批量加标签/移入移出相册(失败报告 x/y)、移入回收站(确认框列全文件名)、取消选择
- 右键菜单:加入/移出对比托盘(攒料 n/9、混选与不足提示、清单管理,工作台入口置灰)、删除
- 详情面板:大图+格式徽章、缺失态「重新定位」(按内容找回)、行内重命名(回车/Esc/失焦提交,同步改磁盘文件、重名加序号)、评分/收藏/删除、标签管理(搜索/按使用数推荐/新建校验/单独移除)、相册归类(菜单含成员数)、EXIF 块(无数据整块隐藏)、直方图(颜色/R/G/B/亮度 + 全部统计值 + 手动刷新,canvas 绘制)、AI 生成参数(提示词卡片可展开复制/模型标签/Workflow 格式化/原始参数,分区折叠)、主题色 ≤6 圆点(缺记录自动提取、旧素材后台补齐)、未选中时显示范围统计;所有写操作乐观更新、失败回滚提示

## M4 预览器 + 视频播放 + 编辑器
- 图片预览器:当前筛选为播放列表、页码、←/→ 切换;滚轮光标锚点缩放 0.1–10、+/- 步进、拖拽平移、百分比显示、0 适应窗口
- 变换直接写盘:水平翻转、R 键旋转 90°;保存中「正在保存…」并锁定按钮与切图;成功后记录(尺寸/大小/主色/缩略图)同步刷新,失败不改记录
- 裁切模式:独立界面、选框拖动/四角手柄/实时像素尺寸,确认写盘
- 全屏;Esc 返回(裁切内先退裁切);视频隐藏图片类按钮
- 自绘视频播放器:播放/暂停/可拖进度条/音量静音/自动循环/时:分:秒/失败原因提示
- 播放分档:ffprobe 探测 → H.264/VP8/VP9/AV1+MP4/WebM 直连流式;MKV/AVI 容器问题 -c copy 转封装缓存(同文件只转一次);HEVC 等如实报「不支持」;缓存 LRU 上限清理且不碰播放中的文件
- 视频信息查看:分辨率/帧率/时长/码率/编码/有无音轨
- 编辑器:亮度/对比度/饱和度滑杆(-100~100)拖动实时预览、应用写盘并同步记录、重置;左右旋 90° 写盘;裁剪;另存为 PNG/JPG/WEBP/BMP/GIF(JPG 透明合白底);处理中禁用按钮

## M5 回收站 + 设置外观 + 可靠性
- 两级删除:移入应用回收站 = 文件移入 `<lib>/trash/` 并记 original_path(确认框列名);恢复还原原位置、占用自动 `name (1).ext`;删除到系统回收站用 shell.trashItem(确认提示);保留天数默认 30(0=不清理),启动时到期清扫
- 回收站视图:瀑布流+卡片元信息+搜索排序,详情只读
- 图库设置:库位置展示、整库复制式迁移(原库保留、完成提示一键重启)、保留天数、缩略图/视频缓存上限(下次启动生效)
- 外观:界面背景(渐变玻璃/预置深色/自定义取色)、查看与对比背景(4 预置+自定义、按明暗自动切换查看器配色)、恢复默认/取消/保存
- 对话框通用行为:Esc 关闭、Tab 焦点循环、点遮罩取消、执行中禁用+「处理中…」、失败原因内联显示
- 外部变动同步:chokidar 监听已导入目录(新导入目录自动纳入)、删除/改名→标记缺失、恢复须内容一致才确认、变化实时刷新界面
- 启动自动维护:缓存压回上限、预览缓存清理、回收区到期清理;先临时文件后落地的写入方式贯穿所有保存与导入

## 风险与预案
- better-sqlite3 原生模块需匹配 Electron ABI:优先用其 Electron 预编译,不行则 electron-rebuild
- ffmpeg-static 约 80MB 下载:慢则切 npmmirror 镜像
- 当前目录在 Program Files (x86):若 node_modules 写入报权限错,停下与你确认换目录
